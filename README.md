# ABS SSH — релизы

Публичный репозиторий только с готовыми сборками **ABS SSH** (SSH / DevOps-клиент для Android и Windows). Исходный код здесь не хранится.

Скачать: раздел [Releases](https://github.com/samur005/abs-ssh-releases/releases).

## Установка

### Android
1. Скачайте `abs-ssh-<версия>-android-release.apk`.
2. Разрешите установку из этого источника (Настройки → Приложения → Специальный доступ → Установка неизвестных приложений).
3. **Важно для перехода с 0.6.0 и раньше:** старые сборки были подписаны debug-ключом. Начиная с 0.7.0 APK подписан релизным ключом, поэтому Android не даст обновить поверх — удалите старую версию (профили сначала экспортируйте: Настройки → Зашифрованная синхронизация → Экспорт).
4. Дальше приложение умеет обновляться само: Настройки → Обновления.

### Windows
- `ABS SSH-<версия>.msi` или `.exe` — установщик; `abs-ssh-windows-portable.zip` — без установки.
- Сборки подписаны **самоподписанным** сертификатом: SmartScreen всё равно покажет предупреждение («Подробнее» → «Выполнить в любом случае»).

## Проверка целостности
В каждом релизе есть `SHA256SUMS.txt`:
```
sha256sum -c SHA256SUMS.txt          # Linux / macOS
Get-FileHash .\файл -Algorithm SHA256   # Windows PowerShell
```
Встроенный обновлятор проверяет SHA-256 (и на Android — совпадение подписи) автоматически.
